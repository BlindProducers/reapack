# Blind Producers ReaPack repository

REAPER plugins from Blind Producers, installed and updated through [ReaPack](https://reapack.com).

## Install

1. In REAPER, choose Extensions > ReaPack > Import repositories.
2. Paste this URL and press OK:

   ```
   https://github.com/BlindProducers/reapack/raw/main/index.xml
   ```

3. Choose Extensions > ReaPack > Browse packages and install the plugins you want.

## Update

Choose Extensions > ReaPack > Synchronize packages. ReaPack updates every installed plugin to its latest version.
